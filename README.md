# 模擬店レジ

文化祭の模擬店向けに作った、iPadで使えるシンプルなレジアプリです。
金券制の模擬店を想定しており、お釣りの計算はありません。1枚のHTMLファイルだけで動きます(サーバー不要)。

## 主な機能

- **レジ画面**: 商品ボタンをタップしてカートに追加、＋/−で個数を調整
- **トッピング**: トッピング付きの商品をタップすると横に選択欄が出て、「追加」で確定(複数選択・個数指定OK)
- **会計の取り消し**: 会計直後の「取り消す」や履歴の「取消」で、直前の選択をレジに戻せる。「選択をすべて消す」で一括クリア
- **履歴・集計**: 売上合計、会計件数、客単価、料理ごと・トッピング込みの価格ごとの集計。集計テキストのコピーも可能
- **商品設定**: 店名、商品名、価格(円)、トッピング(追加料金)を画面上で編集

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る(例: `mogiten-register`)
2. このフォルダの中身(`index.html`、`README.md`、`.nojekyll`)をリポジトリのルートにアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch` にし、Branch を `main`、フォルダを `/ (root)` にして保存する
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## iPadでの使い方

- 公開されたURLをSafariで開く
- 共有ボタンから「ホーム画面に追加」すると、アプリのように起動できる
- 当日は通常のSafariで使う(プライベートブラウズでは記録が残らない)

## データの保存について

- 商品設定と会計履歴は、**使っている端末のブラウザ内(localStorage)**に保存されます
- 端末ごと・ブラウザごとに別々で、他のiPadとは共有されません
- ブラウザのサイトデータを消すと、記録も消えます。終了後は「集計をコピー」で控えを残してください
- 売上データがGitHub上に送られることはありません

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体(HTML・CSS・JavaScriptを1ファイルにまとめたもの) |
| `README.md` | このファイル |
| `.nojekyll` | GitHub PagesでJekyllの処理を使わないための空ファイル |
